# T-Yaşam Windows uygulaması

Bu depo yalnızca T-Yaşam bilgisayar uygulamasının kurulum dosyalarını barındırır. Oyun kendi sunucusundan açılır; kurulum bir kez yapılır, sonraki sürümler uygulama tarafından kendiliğinden indirilir.

Son sürüm: [Releases](../../releases/latest)

Kurulum yayımcı imzası taşımadığı için Windows ilk açılışta "Bilinmeyen yayımcı" uyarısı gösterebilir: "Daha fazla bilgi", sonra "Yine de çalıştır".
